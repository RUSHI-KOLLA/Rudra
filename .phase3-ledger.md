## Rulings
- R1: panel lives in index.html, not app.js/style.css — those are orphaned and
  would throw on load. Reviewer concurred and corrected their own instruction.
  Cost if wrong: none; files stay on a post-Phase-4 cleanup list.
- R2: config relative paths resolve against Path(__file__).resolve().parent
  (repo root IS the package root, so design's `parent.parent` would escape to
  /home/rushi). Cost if wrong: data path points one level high.
- R3: incident_weak_threshold default set to the calibrated 0.3222, not the
  design's pre-calibration 0.45 — design says "0.45 until calibrated" and
  Phase 2 calibrated it. Env var still overrides. Cost if wrong: tiers too
  permissive; reviewer asked for exactly this number in the demo.
- R4: extraction transport/auth failure -> needs_manual_entry (precondition
  trigger_type + >=2 actors unmet), not a bare 500. The design's escape hatch
  exists precisely so a paste can be completed by hand. Cost if wrong: an
  outage looks like a bad paste; the panel says extraction unavailable.
- R5: debate_enabled added to existing GET /api/health (no new route).
  Approved by reviewer in OPEN 4.
- R6: base_rate denominator = curated corpus, numerator = strong tier;
  fallback numerator = trigger_type subset, and per reviewer both the trigger
  type AND the count print on fallback; thin samples (<2) still print the count.
